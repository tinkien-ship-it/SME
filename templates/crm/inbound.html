Cách lấy link kênh MXH & thiết lập để CRM nhận lead

Bấm để thu gọn / mở

Mỗi dòng ở bảng Endpoint theo kênh là địa chỉ nhận lead của SME (adapter). Bạn không lấy “link adaptor” từ Facebook/Zalo rồi dán vào SME — mà ngược lại: copy URL SME → dán vào cấu hình webhook / Make của từng mạng. Khi khách tương tác (form Ads, OA, chat có SĐT), nền tảng gọi URL đó → CRM tạo lead đúng nguồn.

1. Trên Hub này
  • Copy Token
  • Copy URL đúng kênh (facebook, zalo…)
  • Có NV role Nhân Viên Bán Hàng
2. Trên MXH / Make
  • Trigger lead / form / tin có SĐT
  • HTTP POST URL kênh + header X-CRM-Token
  • Meta: Verify Token = Token Hub
3. Kiểm tra CRM
  • Lead thử / Payload gốc
  • Nhật ký inbound = ok
  • Leads + thông báo NV + Dashboard
Facebook / Instagram Lead Ads
  1. Tạo Lead Form trên Fanpage (có trường SĐT).
  2. Khuyên dùng Make: Watch Facebook Leads → HTTP POST URL dòng facebook + Token.
  3. Webhook Meta App: Callback URL = URL facebook; Verify Token = Token Hub; subscribe leadgen.
  4. CRM gán source=Facebook, lưu leadgen_id để không trùng lead.
Zalo Official Account
  1. Bot/OA phải thu được SĐT (form hoặc kịch bản).
  2. Webhook Zalo tool hoặc Make → POST URL dòng zalo + Token.
  3. Gửi kèm tên, SĐT, ghi chú ngắn, id user Zalo (external_id).
Google Ads
  1. Landing: Final URL = link form /lead + UTM mẫu trên Hub → lead vào CRM.
  2. Lead Form Google: Make nhận form → POST URL dòng google + Token.
TikTok Lead Ads
  1. Bật Lead Generation trên TikTok Ads.
  2. Make: Lead mới → POST URL dòng tiktok + Token (adapter hiểu payload gốc TikTok).
WhatsApp Business & Viber
  1. Flow/bot bắt buộc khách để lại tên + SĐT.
  2. POST URL whatsapp hoặc viber + Token (Cloud API / ManyChat / Make).
Website & Hotline
  1. Website: bật form công khai / copy snippet nhúng; không đưa Token ra trình duyệt.
  2. Hotline / giới thiệu: form nhập tay phía dưới trang này — không cần link MXH.

Tài liệu đầy đủ (kỹ thuật + từng bước nền tảng): docs/crm_inbound_mxh_guide.md · endpoint kỹ thuật: docs/crm_inbound_channels.md. SME không thay hộp chat Messenger/Zalo; sau khi có lead, NV làm việc trên Leads → 360°.
